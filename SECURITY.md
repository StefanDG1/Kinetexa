# Security

Kinetexa is under development and is not yet ready for public athlete data or payments.

Report vulnerabilities through GitHub's private vulnerability reporting for this repository when enabled. Do not include credentials, personal fitness files, private routes or exploit details in public issues. If private reporting is unavailable, contact the repository owner privately through GitHub before sharing sensitive details.

Security fixes must include regression coverage for the affected boundary. Cross-athlete authorization, private object access, share geometry, parser limits, consent enforcement and signed billing events are release gates.

The release process must identify an operational security contact and validate the disclosure channel before public launch.
