# Security

Kinetexa is under development and is not yet ready for public athlete data or payments.

Report vulnerabilities privately to contact@exponentialeducation.ro. Include the affected feature, a concise reproduction using synthetic data, and the potential impact. Do not send credentials, personal fitness files or private routes. Do not publish exploit details in public issues before the report has been reviewed and the affected users protected. GitHub private vulnerability reporting may also be used when available.

Security fixes must include regression coverage for the affected boundary. Cross-athlete authorization, private object access, share geometry, parser limits, consent enforcement and signed billing events are release gates.

The public contact was supplied by the owner. Receipt and response handling remain a release verification item. See the [threat model](docs/threat-model.md) and [incident response procedure](docs/incident-response.md).
